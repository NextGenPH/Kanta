# Kanta 🎤

Kanta is a premium Android karaoke and video player application designed for discovering, queuing, and enjoying music with a high-performance, YouTube-inspired experience.

## 🌟 Key Features

*   **Persistent Mini Player:** Watch and listen without interruption. Minimize the player into a compact footer while you browse the library—playback never stops.
*   **Seamless YouTube Integration:** Stream high-quality karaoke tracks directly from YouTube.
*   **Material 3 Design:** A modern, clean, and responsive UI with "Lift on Scroll" toolbars, dynamic filter chips, and smooth motion transitions.
*   **Advanced Search Experience:** 
    *   Full search history management with individual item deletion.
    *   Real-time trending suggestions and recommendations.
    *   Voice search support for hands-free discovery.
*   **High Performance:** Optimized RecyclerView architecture for smooth 60fps scrolling and efficient memory usage, even with large playlists.
*   **Smart Queue Management:** Easily manage your "Up Next" list, reorder songs, and autoplay recommendations.
*   **Remote Web Control:** Pair with a web-based player using a simple code for a cross-device experience.
*   **Automated Updates:** Stay on the latest version with integrated NextGenUpdater support.
*   **Adaptive Layouts:** Fully optimized for both Phones (Bottom Navigation) and Tablets (Navigation Rail & Grid view).

## 🚀 Getting Started

### Prerequisites
*   Android device running API 24 (Nougat) or higher.
*   Stable internet connection.

### Installation
1.  Clone the repository:
    ```bash
    git clone https://github.com/NextGenPH/Kanta.git
    ```
2.  Open the project in **Android Studio (Ladybug or newer)**.
3.  Sync Gradle and build the project.
4.  Run on your device or emulator.

## 🛠 Usage

1.  **Discovery:** Browse the Home feed using dynamic filter chips (Trending, New, Popular, or specific Artists).
2.  **Playback:** Tap a song to start the immersive player.
3.  **Multitasking:** Press "Back" or use the minimize arrow to shrink the player. The **Mini Player** will stay active at the bottom while you continue browsing.
4.  **Search:** Tap the search icon to find specific tracks. Managed your recent searches or explore "Trending Now" recommendations.
5.  **Remote Mode:** Use the Cast icon in the navigation bar to connect Kanta to a web-based playback session.

## 🔐 Permissions
*   `INTERNET`: Required for streaming and searching songs.
*   `RECORD_AUDIO`: Required for the Voice Search feature.
*   `ACCESS_NETWORK_STATE`: Used to check connectivity during startup.
